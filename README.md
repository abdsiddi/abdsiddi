## About

Cybersecurity student at Air University (BSc, expected July 2027), aiming for SOC analyst and cloud security roles. I learn by building home labs: deploy something, attack it, detect it, then write up what broke and how I fixed it.

Coursework: Network Security, Ethical Hacking & Penetration Testing, Digital Forensics & Incident Response, Information Assurance & Risk Assessment.

## Featured labs

| Lab | What I did |
| --- | --- |
| [**Threat Intelligence Honeypot Lab**](https://github.com/abdsiddi/MHN_Splunk_lab)<br>MHN + Splunk on AWS | Deployed Modern Honey Network and a Dionaea honeypot on an EC2 instance to capture live attack traffic. Sent the logs to Splunk Enterprise through the HTTP Event Collector with a custom Python forwarder, then built dashboards of attack geography and attacker behavior. |
| [**Cyber Threat Intelligence Home Lab**](https://github.com/abdsiddi/elastic-threat-detection-lab)<br>Elastic + Sysmon | Built an isolated Elastic SIEM fed by Winlogbeat and Sysmon telemetry, wrote KQL detection rules and mapped them to MITRE ATT&CK. |
| [**RHEL 10 STIG Hardening Lab**](https://github.com/abdsiddi/rhel10-stig-hardening-lab)<br>OpenSCAP + Ansible | Scanned RHEL 10 against the DISA STIG profile and traced failed checks back to NIST 800-53 controls. Fixed findings by hand and with an Ansible playbook, taking compliance from 48% to 95.37% (438 passed, 19 failed) over three rescan cycles. |

Also: a distributed master-worker port scanner, ML-based CCTV tamper detection, and an on-premise LLM platform (Qwen2.5) for insider threat detection, currently in progress.
